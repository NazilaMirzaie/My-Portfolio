# Nazila Mirzaie — Personal Portfolio

A responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**.

## Pages / Sections
- Home
- About
- Projects
- Skills
- Education
- Contact

All sections are part of one responsive page with navigation links.

## Run it
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## Personalize it
- Replace `photo_2026-10-19_20-45-56.jpg` with your preferred portrait (keep the same filename).
- The Asma Ul Husna project uses `assets/asma-ul-husna-background.png`.
- Update the email, social links, project links, dates, and education details in `index.html`.
- Adjust skill-bar widths in `index.html` by changing values such as `--level:72%`.
- Edit colors and spacing in `style.css`.

## Contact form note
The contact form opens the visitor's default email app using `mailto:`. It does **not** send messages directly from the website. To receive submissions without an email app, connect a backend or form service.

## Important
The GitHub and LinkedIn links are placeholders. Replace them with your real profile URLs before publishing.
